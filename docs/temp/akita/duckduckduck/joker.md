# 奇术师

## 概述

那是魔法吗？他们总会被问及这样的问题。然而一个合格的奇术师当然不会回复，神秘性是他们生存的第一原则。

使用令人眼花缭乱的戏法华丽地表演，正是奇术的本义。

## 必要条件

* 至少拥有3种不同的基础职业
* 拥有至少7经历点

## 关键属性

* 敏捷
* 智力

## 熟练技能

* 妙手
* 乔装
* 若拥有“武者”职业，可选择一样武器技能作为额外熟练技能
* 若拥有“哨兵”职业，可选择一项挂钩属性为敏捷的泛用技能作为额外熟练技能
* 若拥有“卫士”职业，可选择一项挂钩属性为体质的泛用技能作为额外熟练技能
* 若拥有“旗手”职业，可选择一项挂钩属性为智力或魅力的泛用技能作为额外熟练技能
* 若拥有“专家”职业，可选择一项特殊技艺作为额外熟练技能
* 额外熟练技能至多生效3个

## 职业特性

行动轮开始时，可以将回合拆分成由基础行动点组成的基础回合和由额外行动点组成的额外回合；基础回合正常按照敏捷属性计算，额外回合可以在任意角色回合后插入。两次使用中间需有一行动轮间隔。

4|战技“幸运七”升级：额外行动轮中所有检定附带一次该战技的奖励效果<br>特殊战技“奇术时刻”升级：使用后额外叠加2层“先导之奇术”的奖励效果

6|职业熟练技能升级：额外熟练技能至多生效5个<br>职业特性升级：继承一项基础职业的职业特性<br>获得战技：同病相怜

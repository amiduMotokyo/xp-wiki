# 生灵特性

顾名思义，这里指的就是生灵所具有的异于其他群体或个体的特点。你可以通过吸收其他生灵的肉体来解析出想要的能力，也可以通过消耗足够的肉体强化点数进行一次满足条件的突变进化；但需特殊注意，如果你未满足一个特性的突变条件，但你仍然吸收到了该特质时，该特质禁用至你满足突变条件。

生灵特性无法因任何非自身效果而失效，可当做被动战技写入表格，但应在分类中标注由战技改为生灵特性。

若无特别说明，每项特性只能获得一次。

## 标准能力

这一级别不需要你拥有任何其他要求，只需要消耗少量的点数就可突变；拥有其特性的生灵随处可见，无需特殊的魔法与知识也能吸收。

名称|所需点数|突变所需要求|吸收获取要求|效果
:--:|:--:|:--:|:--:|:--:
身体强化1|2|无|种族特性中拥有对应奖励骰|获得“xx（该属性）强化1”，效果为该属性+5：可重复获得本技能强化不同属性，每获得一次本技能所需点数+1。
生命力强化1|3|无|无|最大HP+5
精神力强化1|3|无|无|最大SP+5

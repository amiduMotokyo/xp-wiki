# 敕令系魔法

## 敕令系魔法共通效果

### 与天地沟通的方式

* 描述：利用特殊的仪式与语言，沟通世界并令其为你服务。施法过程中大部分是通过共振引起空气中的魔粒子共鸣，使其像铁与磁铁被磁化一样扩散并产生效果，引起效果的时间因人与环境而不同。
* 效果：**敕令系法术与其他灵魂之言法术共享同一个魔法精通。**<br>即便是仪式之法也会享受魔法精通的效果，**每有10级灵魂之言精通，你的敕令系法术所需要准备的时间缩短半行动轮，可减少至立刻触发，此效果后于仪式之法等级生效。**<br>你与天地之间也可像人与人之间一样，提前熟悉；敕令系的施法素材极为特殊，其本质是已引起与你共鸣的魔粒子量，**施法时素材不会消耗，但会在进行跨地图传送与长休后降低一半等级，战斗结束后会降低至4级共鸣；每2个天地共鸣等级也会减少敕令系法术所需要准备的时间缩短半行动轮。**<br>在默认情况之下你同一时间只能准备一个敕令系法术，且无法使用该法术相关外的任何话术相关效果直到你准备完成。

## 基础敕令

### 敕令：共鸣

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">；力场型</a>
* SP消耗：10
* 素材要求：天地共鸣-0

#### 效果

* 效果：进行一次该灵魂之言（精通）的鉴定，若结果大于20x当前天地共鸣等级则使其提升1级，至多提升至6级。<br>如果在长休时释放不论是否成功均可额外消耗1长休点使素材等级降低一半改为降低1级。
* 准备时间：1行动轮
* 弱点：头

### 敕令：猛击

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>
* SP消耗：5
* 素材要求：天地共鸣-1

#### 效果

* 效果：选择一地点为中心，对其为中心区域的天地共鸣等级-2（最低为1）格为范围内的所有敌方造成3*天地共鸣等级的所选元素伤害
* 准备时间：2行动轮
* 弱点：头

### 敕令：守护

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>
* SP消耗：5
* 素材要求：天地共鸣-1

#### 效果

* 效果：选择一地点为中心，对其为中心区域的天地共鸣等级-2（最低为1）格为范围内的所有友方施加5x2天地共鸣等级的所选元素的额外生命值，在减少该额外生命值时敌人抵抗2倍伤害的元素印记
* 准备时间：2行动轮
* 弱点：头

## 中级魔法

### 敕令：充盈

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>
* SP消耗：0
* 素材要求：天地共鸣-3

#### 效果

* 效果：指定一名目标为其回复当前天地共鸣等级x5的SP，那之后降低1级天地共鸣等级。
* 准备时间：3行动轮
* 弱点：头

### 敕令：狂潮

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">立场型</a>
* SP消耗：10
* 素材要求：天地共鸣-3

#### 效果

* 效果：由施法者为中心对半径3x当前共鸣等级内的所有非友军/中立目标，（包括可见与不可见，生物与非生物）造成2x当前共鸣等级的固定伤害。<br>若命中数量超过当前共鸣等级则结束后降低1级共鸣等级。
* 准备时间：3行动轮
* 弱点：头

## 上级魔法

### 敕令：驱灵化域

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">立场型</a>
* SP消耗：25
* 素材要求：天地共鸣-5

#### 效果

* 效果：将选定整个场地中的某个的地形替换至全场（包括空气方块），并且你和你的友军将免疫该地形。同时敕令：猛击与敕令：守护的效果将扩散至全场；敕令：狂潮将不再降低共鸣等级且伤害增加0.5倍。
* 准备时间：7行动轮
* 弱点：头

### 敕令：狂灵之宴

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#仪式之法" target="_blank">仪式之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">立场型</a>
* SP消耗：30
* 素材要求：天地共鸣-6

#### 效果

* 效果：将你的天地共鸣等级提升至7级，同时若敌方拥有天地共鸣则强制下降3级。<br>在你的每个回合开始时与结束时分别立刻免费释放共1D5次的敕令：猛击、敕令：守护、敕令：充盈与敕令：狂潮。
* 准备时间：7行动轮
* 弱点：头

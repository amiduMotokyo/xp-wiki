# 附言系魔法

## 附言魔法共通效果

### 灵魂的语言

* 描述：灵魂之言的附言法术本质上是一种使用魔力驱动的特殊语言，所以其存在本身可以视作是一种话术。
* 效果：**附言系法术与其他灵魂之言法术共享同一个魔法精通。**<br>附言系法术可以通过一个成功的释放鉴定将法术效果附加至自身下一次使用的话术上，也可直接使用法术对抗流程。<br>**附着至下个话术时将按照话术流程生效，且法术附加的印记减半。正常的法术对抗不受减半影响，且附言系法术视作话术且享受所有的话术效果增益。**（这也包括了附言系法术本身，但选择作为附加效果的那个法术造成的印记仍然减半。）<br>**所有附加的异常效果均只有“话术”词条**


## 基础附言

### 附言：顺从

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#心神之法" target="_blank">心神之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>

#### 效果

* 初始：选择感知范围内一名可见目标对其附加（1+差值因子/2向上取整）层“屈从印记”。当目标在附言：顺从效果结束时已经累计6层“屈从印记”时，则可消耗该数量印记强制使其进行一个至多消耗2ap（可透支）的非敌意行为，该行为需要你知道效果且目标可执行。
* 10级进阶：所需累计层数从6降至4层。
* 20级进阶：若目标累计了8层“屈从印记”则非敌意行为可改为敌意行为。
* 30级进阶：触发累计效果时，可额外消耗4层“屈从印记”使累计效果再生效一次。
* 累计效果无法因过载效果增幅。

### <h id="屈从印记">屈从印记</h>

* 效果：每层屈从印记将增加鉴定结果1点，至多增加10点。
* 解除手段：战斗结束后自动解除
* 词条：话术

### 附言：欢欣

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#心神之法" target="_blank">心神之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>

#### 效果

* 初始：选择感知范围内一名可见目标对其附加（1+差值因子/2向上取整）层“鼓舞印记”。当目标在附言：欢欣效果结束时已经累计12层“鼓舞印记”时，则可消耗该数量印记获得消耗层数/3的“欢欣印记”
* 10级进阶：所需累计层数从12降至6点。
* 20级进阶：获得“欢欣印记”层数提升至消耗“鼓舞印记”层数/2。
* 30级进阶：触发累计效果时，可使目标范围3格内的一名单位获得“欢欣印记”层数等量的“鼓舞印记”层数。
* 累计效果无法因过载效果增幅。

### <h id="欢欣印记">欢欣印记</h>

* 效果：判定结果减少相当于欢欣印记层数的数值，至多减少15点。拥有鼓舞印记时鼓舞印记效果减少欢欣印记的层数。
* 解除手段：战斗结束后自动解除
* 词条：话术

## 中级魔法

### 附言：静心

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#心神之法" target="_blank">心神之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>

#### 效果

* 初始：选择感知范围内一名可见目标选择清除其至多（1+差值因子/2向上取整）层带有“话术”标签的印记类异常状态，可将每3层清除次数换作解除1次带有“话术”标签的一般类异常状态。
* 10级进阶：当目标在附言：静心效果结束时，回复未使用清除层数*2的SP
* 20级进阶：使用时额外新增可将每3层清除次数换作“静心印记”
* 30级进阶：使用后目标每清除3层有“话术”标签的印记类异常状态，则恢复2SP。

### <h id="静心印记">静心印记</h>

* 效果：每层静心印记可选择抵消被施加带有“话术”的异常状态，每1层抵消1层印记类异常状态，每3层抵消1层一般类异常状态。
* 解除手段：战斗结束后自动解除
* 词条：话术

## 上级魔法

### 附言：疯狂

#### 魔法流派与消耗

* <a href="/rules/V4.x rules/8·magic/#心神之法" target="_blank">心神之法</a>
* 击发类型：<a href="/rules/V4.x rules/8·magic/#魔法的击发类型" target="_blank">定点型</a>

#### 效果

* 初始：选择感知范围内一名可见目标，为其附加（1+差值因子/2向上取整）层癫狂印记。
* 10级进阶：若目标已经有6层屈从印记则将6层屈从印记转化为3层癫狂印记。
* 20级进阶：若本次对抗至少差值因子为3，则将附加层数翻倍。
* 30级进阶：若至少差值因子为5，则可对目标一圈范围内的一名目标施加一半（向上取整）的层数。

### <h id="癫狂印记">癫狂印记</h>

* 效果：每层癫狂印记在进行任意行为时将进行一次1d100，若结果小于20*当前层数则会将行为进行翻转，翻转效果将由施法者决定。（例如移动变为反向，治疗友军变为治疗敌军，伤害敌人变为伤害友军，在不改变行为效果的情况下更换行为目标。）
* 解除手段1：触发癫狂后自动解除5层数。
* 解除手段2：战斗结束后自动解除。
* 词条：话术

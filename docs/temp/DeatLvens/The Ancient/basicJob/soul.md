# 灵魂之路

## 概述

踏上研究灵魂之路的旅途，学习如何操控自身的灵魂去影响万物。你会学会如何号令下至草木，上至天地的技巧；但也终归是技巧，如果自身不够强大也终不过是昙花一现。

## 必要条件

* 无

## 关键属性

* 魅力
* 魔力

## 熟练技能

### 灵魂之言（语言/魔法精通）

* 描述：让灵魂像声带一样发出只共振魔法粒子的波纹，并附带上使用者所表达的意愿，让万物之中携带的灵魂执行其意志。但是否能够成功使对方屈服取决于对方和使用者之间的差距。
* 挂钩属性：魔力
* 被动效果：你可以沟通万物之中携带的微小灵魂与魔粒子，并得到一定的信息。当你进行“感知”鉴定时，该鉴定挂钩属性可以改为魔力，且能够穿过障碍物，但穿过障碍物时额外消耗1格距离。
* 长休效果：
* 沟通万灵【1长休行动点】：接下来的一天中你通过魔力属性使用“感知”的非对抗鉴定可以重掷1次，且选择两次中较好的结果。
* 淬炼灵魂【3长休行动点】：进行一次你的魔力属性成长，并进行一次灵魂之言鉴定，成功则该次鉴定将获得等同于六次灵魂之言系法术释放的经验。
* 10级进阶：你可以使用灵魂之言进行语言沟通，此时视作你使用对方的官方语言进行对话，但并不代表你学会读写该种语言。
* 20级进阶：在使用灵魂之言进行沟通的过程中你也可以学会对方语言，且可直接学习对方地区方言，但并不代表你学会读写该种语言。你可以额外学习灵魂之言等级/5个语言。
* 30级进阶：你可以使用灵魂之言进行语言沟通，此时视作你使用对方的地区方言进行对话，但并不代表你学会读写该种语言。

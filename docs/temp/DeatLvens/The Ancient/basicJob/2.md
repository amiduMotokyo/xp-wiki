# 圣诞者

## 概述

再诞者是处于某种目的，为了“复活”某人而产生的。其原理是将想“复活”的人所拥有的记忆尽可能的从原本的灵魂中剥离并注入一个全新的、定制化的胚胎当中，这个胚胎是由多个议会下属部门联合创作完成的，其成本极高，除家族之外的小家庭根本无法负担。所以圣诞者其实也相当于是高贵的祖民对于自己死亡的一种别样的安全保险。但相应的，有些家庭做不到那么昂贵的定制，但也可以为自己的孩子进行一定程度上的“优待”，以期未来这笔投入会得到更高的回报。

## 必要条件

* 车卡结束后全属性和≥280点（不包括装备与临时效果）

## 关键属性

* 无

## 熟练技能

* 无
  
## 职业特性

本特性无需主职业也将强制生效：在车卡（角色创作）阶段中加点所提升的属性可满足必要条件，在结束车卡阶段后本职业无法通过任何手段升级。

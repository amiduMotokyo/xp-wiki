# 血肉之路

## 概述

通过特有魔法来改变肉体，可以是不稳定的短效突变，也可以是长久化的彻底融合，甚至也可以是单纯精化自身肉体，或许你可以再贪心一点，你全都要？

*弱者需凝聚智慧，而强者会淬炼肉体。你的身体就是你最好的武器，当你不再会被毒素影响、不再会窒息而亡、当你在天空睥睨万物、当你踏平山丘、当你在亲手粉碎仇敌的时候，你会感谢我、感谢你今天所做的决定——与我一同研习这血肉之理。————第4代战争殿主就任演讲词*

### 血肉之理（魔法精通）

* 描述：吸收、分析、理解、融合血肉的能力，将万物的优点集于自身，亦或是将自身的肉体精化到极致？加亦或是减，取决于你。
* 挂钩属性：（力量+体质）/2（奖励骰计算为较多者，不叠加）
* 被动效果：饱食度转化为“能量储备”，上限改变为5+体质/5。当你食用食物时，每5点HP回复量转化为1能量储备；你也可以直接食用食材（包括生吃与大餐）来增加2倍于总素材品质的能量储备。
* 长休效果：
* 吞食【1长休行动点】：寻找一切可以消化的东西并将其吃下，无论成功与否获得2+差值/5（四舍五入，至少为0）的能量储备。
* 能量转化【1长休行动点】：将至少10点“能量储备”转化为1肉体强化点数。
* 融合吸收【1长休行动点】：消耗1肉体强化点数获得1次任意属性成长机会，或消耗肉体强化点数进行一次特性突变。<br>可在不消耗长休点的情况下对某一尸体使用，效果改为：进行一次本技艺的鉴定，若成功则摧毁尸体，选择获得其一个生灵特性至多依此法获得总经历点/5个（向下取整，上限时可以替换已有），并获得1+其经历点/10（向下取整）肉体强化点数；或选择获得两倍肉体强化点数。此效果初始可用3次，每次长休恢复使用次数至3次。

# 猎兽——陆生

这些是原为陆生生物的猎兽，在经过改造之后作为日常狩猎或是放牧的兽类。它们有些温和但有些仍具有较强的攻击性。

**武器熟练度为其天生武器的相似种类，不代表拥有，且只会习得固定武器通用技能。**

## 磐兽

* 占地：3×4或者3x5
* 属性：力量40，敏捷35，体质75，智力15，魅力20，魔力15
* 生命值：85
* 精神力：15
* 天生武器攻击范围：3
* 天生武器威力：15
* 天生护甲：头部20（冠角），躯干12，左右手7，左右脚5
* 熟练技能：大锤+30、防御+15、抵抗+30、
* 衰减速度：进攻10、防守15
* 战技：滚动（特战）、蜷缩（特战）、钢毛、碎甲、粉碎防御、破阵、
* 常见数量：3~5只
* 挑战等级：4经历点

磐兽原本是一种带有大型冠角的羊，在融合了牛、马、犰狳之后虽然仍有标志性的毛与角，但实质上已经是一种杂食性的动物。它们大多为单组或两组家庭一起生活，大多数情况下会放养在草甸与森林的交界处。磐兽因在危险下会蜷缩成球状，而大型冠角与毛裸露在外，使用坚硬的毛与角冲撞敌人就像巨石滚过，因此而得名。虽然大多数情况下会收集毛与角，但值得一提的是因为肉质鲜美偶尔也会进行集中养殖来为餐厅提供原料。

## 犁兽

* 占地：3×4或者4x5
* 属性：力量55，敏捷25，体质75，智力10，魅力10，魔力5
* 生命值：85
* 精神力：5
* 天生武器攻击范围：4
* 天生武器威力：12
* 天生护甲：头部10，躯干13，左右手8，左右脚7
* 熟练技能：战斧+30、防御+15、搬运+15、抵抗+30、
* 衰减速度：进攻15、防守10
* 战技：翻搅（特战）、践踏（特战）、锋利之角、猛力攻击、战斗狂热、气吞山河、
* 常见数量：2~3只
* 挑战等级：4经历点

犁兽是出于对耕地的需求，以牛为主体改造而成，硕大且锋利的角被用于翻土。它们大多集群养殖，少数情况下会在各种开阔地带以家庭为组生存。

## 狩狼

* 占地：2x1
* 属性：力量35，敏捷55，体质25，智力15，魅力5，魔力5
* 生命值：35
* 精神力：5
* 天生武器攻击范围：1
* 天生武器威力：8
* 天生护甲：头部4，躯干7，左右手2，左右脚1
* 熟练技能：爪+15、闪避+15、
* 衰减速度：进攻5、防守10
* 战技：撕咬（特战）、团队狩猎、快速进食、趁虚而入、
* 常见数量：5~10只
* 挑战等级：2经历点

最早一批的改造动物，由于初期技术的不稳定所以只进行了相当于现在最程度的突变，仅仅强化了身体能力，与普通的狼几乎没有区别。

* 占地：3x2
* 属性：力量55，敏捷65，体质45，智力15，魅力15，魔力15
* 生命值：55
* 精神力：15
* 天生武器攻击范围：2
* 天生武器威力：12
* 天生护甲：头部7，躯干11，左右手6，左右脚5
* 熟练技能：爪+30、防御+15、闪避+15、战术+15、抵抗+15、

## 裂爪兽

* 占地：3x5站立3x3
* 属性：力量75，敏捷45，体质85，智力25，魅力15，魔力15
* 生命值：105
* 精神力：15
* 天生武器攻击范围：3
* 天生武器威力：15
* 天生护甲：头部9，躯干16，左右手8，左右脚9
* 熟练技能：大锤+30、爪+30、防御+30、抵抗+15
* 衰减速度：进攻15、防守10
* 战技：沉重体态、团队狩猎、厚实甲壳、碎甲、致命一击、碎地拳、断筋击、趁虚而入、卧薪尝胆、
* 常见数量：1~2只（可有幼崽）
* 挑战等级：10经历点

以实验性质目的创造出的怪物，杂糅了极大量的生物基因，主体依稀可以判断出是熊。由于未曾考虑过将其作为放牧对象，所以绝大部分情况是当做狩猎祭的猎杀目标培育而出。

# 第二章：种族

艾克苏普世界群中生活着各式各样的种族社群，在一开始你可以根据自己对它们第一印象进行挑选，不过要注意战役简介中的种族限制。

当你对艾克苏普世界观有了一定的了解之后，角色扮演将会变得更有目的性。通过点击下面的超链接可以跳转到种族及其势力的简介页面。

## 扩展种族

扩展种族拥有更加复杂的种族特性，部分种族特性比起基础种族而言会稍显强势/弱势，因此所有扩展种族会有“种族经历点补正值”来平衡这一点。

你需要在建卡时额外消耗与“种族经历点补正值”等量的经历点，才能选择对应的扩展种族。在低经历点开团的情况下，这有可能将你的当前经历点扣成负数，这是不被允许的情况，你可以选择主动降低你的一些初始属性，获取一定的补偿经历点，来将初始经历点修正回0点，或是放弃选择高种族补正值的种族。

    四臂蚁族的4只手可以提供许多便利：你可以最多同时持有1个主武器+3个副武器，总共4个单手武器进行战斗，且交换这些武器在你手中的位置都只需要1行动点。在双持进攻中，你甚至可以在2行动点内同时使用这4个武器发起进攻。不过，这种方式下进攻的上限具有一定的限制：具体来说，那些可以免除双持进攻惩罚的技能，只能对其中最多2个武器生效（即一个主武器和一个副武器的组合）。

    除了这些在战斗层面的便利，四臂蚁族的4只手也可能在rp阶段给你的某些行为带来奖励。请与主持人商量是否可以获得这些奖励。

## <h id="语言">语言</h>

语言的学习可以使你更加方便地与他人沟通，同时任何话术效果只有在和对方语言互通时才能起到效果。

### 官方语言

官方语言是某个文化圈的通用语言，该文化圈使用的文字也与该文化圈的官方语言相对应。学习语言主要也就是学习某个文化圈的官方语言。

魔族语|魔族

基本准则是一个文明对应一个官方语言。若将来的团有新的文明诞生，或是于某文明共用一种语言的情况，请主持人先在战役简介或团内和玩家说明清楚，然后再与带TG商议是否将新语言加入表格当中。

### 语言不通的惩罚

在辨识某文化圈的文字的场合下，如果辨认者不会该文化圈的官方语言，那么会遇到如下惩罚：

* 若没有翻译工具的帮助（比如字典），则无法辨认文字
* 若有翻译工具的帮助，则辨认文字需要用到的检定（如见闻、灵知等）会获得一枚惩罚骰

在语言沟通的场合下，如果沟通的双方找不到任何一个双方都会的官方语言，那么沟通时会遇到如下惩罚：

* 无法听懂对方讲的话（文字用乱码表示）
* 无法对对方使用任何话术

另外，语言不通时，一个成功的乔装检定可以让你和对方进行大概的沟通，此时主持人只会从第三人称告诉你对方大概的意思，并不能避免上述的惩罚

### 母语

每个角色建卡时自带该角色所处文化圈的官方语言，作为母语。

通常情况下，对于任意语言，其母语者在语言的直觉感知、隐性知识与综合运用能力上，普遍优于后天学习掌握该语言的人。

### 学习语言

有以下3种途径习得新的语言：

* 花费1经历点，或者成长免费送的1点副职点来习得一个未掌握的官方语言
* 自动掌握（对抗团中可改为征得允许）所有队友所习得的所有语言的日常用语，但无法进行复杂的组词成句
* 去商店购买词典，长休时进行学习：消耗2长休行动点，进行灵知检定，学会词典中的语言需要如此成功2次，每当你学习某个语言失败一次，你下次再学习这一语言时就能多获得一枚奖励骰
